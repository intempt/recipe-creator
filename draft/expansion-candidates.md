# Highly engaged users below enterprise

## Step 1: Build the expansion-candidate list

Build a segment of users named "Expansion Candidates". A user is in the segment only when all of these are true: their Plan attribute is not "enterprise", they did the Session start event 8 or more times in the last 14 days.

## Step 2: Send an upgrade email

Generate a designed marketing email for the users in "Expansion Candidates" highlighting one feature available only on a higher plan. Three sentences, confident and helpful tone, no discount language, one button linking to the upgrade page. Use the result of "Build the expansion-candidate list".

## Step 3: Notify growth

Generate a plain-text email to the growth team distribution list listing the users in "Expansion Candidates" so outreach can be timed to their actual usage instead of a generic drip. Use the result of "Build the expansion-candidate list".
