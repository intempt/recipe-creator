# Power users

## Step 1: Build the power-user list

Build a segment of users named "Power Users". A user is in the segment only when all of these are true: their Lifetime value attribute is more than 0, they did the Session start event 10 or more times in the last 30 days.

## Step 2: Invite them to the referral program

Generate a push notification for the users in "Power Users" inviting them to join the referral program. Title under 40 characters, one short body line, friendly and appreciative tone, deep link to the referral program page. Use the result of "Build the power-user list".

## Step 3: Share the shortlist with growth

Generate a plain-text email to the growth team distribution list listing the users in "Power Users" as candidates for case studies and advocacy, not just referrals. Use the result of "Build the power-user list".
