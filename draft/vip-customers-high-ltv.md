# VIP customers

## Step 1: Build the VIP list

Build a segment of users named "VIP Customers". A user is in the segment only when all of these are true: their Lifetime value attribute is 1000 or more, they did the Session start event at least once in the last 7 days.

## Step 2: Send a VIP recognition email

Generate a designed marketing email for the users in "VIP Customers" thanking them for their loyalty and inviting them into VIP recognition. Three sentences, warm and appreciative tone, no discount language, one button linking to the rewards or early-access page. Use the result of "Build the VIP list".

## Step 3: Alert the concierge team

Generate a Slack message to the concierge team channel listing the users in "VIP Customers" so the team can give each one a personal welcome into the program. Use the result of "Build the VIP list".
